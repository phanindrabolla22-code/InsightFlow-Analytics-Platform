# 📊 BI Dashboard - Data Analyst Project

A complete end-to-end Data Analytics web application built using Streamlit.

---

## 🚀 Features

- 📂 Upload CSV / Excel files  
- 🧹 Smart Data Cleaning (mean / median handling)  
- 📊 Data Overview (rows, columns, missing, duplicates)  
- 📈 Interactive Charts (Bar, Line, Histogram, Pie)  
- 🧠 Insights Engine (automatic business insights)  
- 📥 Download Executive Report (ZIP file with charts + summary)

---

## 🛠️ Tech Stack

- Python  
- Streamlit  
- Pandas  
- Matplotlib  
- Seaborn  
- Openpyxl  

---

## 📁 Project Structure
A modular Streamlit BI Dashboard:

- `app.py` → Main entry point
- `pages/` → Multi-page dashboard system
- `Cleaning.py` → Data preprocessing
- `Dashboard.py` → Visual analytics
- `Insights.py` → Business insights engine
- `Results.py` → Final report generation
